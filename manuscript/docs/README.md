# Component Documentation Index

This directory contains quick-reference documentation for each implementation component of the single Krishi Vaidya system. These files are not the final manuscript prose. They are source maps for writing the manuscript accurately.

## Component folders

| Folder | Component | Purpose |
| --- | --- | --- |
| `krishi_vaidya_yolo/` | YOLO object-detection model | Detection dataset, model training, validation, figures, tables, and manuscript section plan. |
| `krishi_vaidya_vlm/` | VLM disease model | Qwen2.5-VL LoRA fine-tuning, dataset assets, evaluation outputs, and limitations. |
| `krishi_vaidya_backend/` | Backend API | Express/TypeScript API structure, domain models, routes, services, integrations, and missing diagrams. |
| `krishi_vaidya_mobile_app/` | Mobile app | Expo/React Native app structure, features, workflows, local ML/offline support, and missing screenshots. |

## Usage

Read the relevant component folder before writing any manuscript section. Use the source paths and asset maps in each folder to verify claims before adding them to LaTeX chapter files.
