# Manuscript Progress Documentation

This folder contains planning and tracking files for writing the Krishi Vaidya manuscript. Component-specific quick documentation lives in `../docs`.

## Files

- `ledger.md`: master list of manuscript sections, figures, tables, placeholders, and required elements.
- `progress.md`: current completion state and blockers.
- `table_of_contents_progress.md`: detailed working table of contents with chapter, section, subsection, and sub-subsection status.
- `priority.md`: correct writing order for the manuscript.
- `assets_inventory.md`: inventory of ready assets and missing artifacts.
- `figure_map.md`: placement plan for figures and tables.
- `citation_plan.md`: citation policy and literature review planning.
