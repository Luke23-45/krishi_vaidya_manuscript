    \quad \textbf{6.}\;Listen on PORT}};

\node[note] at (0,-14.5) {
  \textbf{Design rationale}\;\textcolor{muted}{\textemdash}\;
  Middleware executes in strict registration order.
  Public routes (\texttt{/health}, \texttt{/diagnose},
  \texttt{/auth/*}) bypass JWT verification; protected routes
  inject \texttt{req.user} via \texttt{authMiddleware}.
  Controller\,\textrightarrow\,Service\,\textrightarrow\,Repository\,\textrightarrow\,MongoDB
  enforces separation of validation, business logic,
  and persistence.};
