  repositories isolate persistence mechanics behind
  \texttt{BaseRepository\textless T\textgreater}.
  The DI container wires everything at bootstrap so
  each layer depends only on abstractions, not concrete
  implementations. JWT user context from \texttt{req.user}
  propagates through the service layer for ownership checks.};
