\PrelimHeading{Abstract}
\PrelimEntry{Abstract}

Timely crop disease diagnosis remains a critical gap in smallholder agriculture, where access to
expert pathological assessment is geographically and temporally constrained. This project
investigates how object detection, vision-language modelling, backend orchestration, and
offline-aware mobile delivery can be integrated into a single crop-health diagnosis-support
system for the Nepalese agricultural context.

Krishi Vaidya composes four subsystems into an image-to-advisory workflow. The YOLO subsystem,
trained on a curated dataset of 30,981 images and 147,467 annotations across eleven plant-part
classes, achieves F1 0.73 and mAP@50 0.76 at the best training epoch, with INT8 quantization
preserving 98 percent of baseline detection performance at 1.87$\times$ compression. The VLM
subsystem, built on Qwen2.5-VL-3B-Instruct with LoRA adapters and 4-bit quantized training,
completes fine-tuning within a 13 GB GPU memory envelope but reveals a 67.7 percent parse-error
rate on the independent test split---identifying structured output reliability as the primary
open challenge. The Express/Mongoose backend validates uploaded images, orchestrates VLM
inference, generates schema-validated advisory responses, and exposes authenticated API endpoints
for eight application domains with scan-focused automated test coverage. The React Native/Expo
mobile application provides bilingual farmer-facing workflows including scan capture, local
SQLite persistence, offline queue management, crop-plot record keeping, and structured diagnosis
display.

The integrated diagnosis path connects mobile image capture through backend validation, VLM
inference, advisory generation, and farmer-facing result delivery. Runtime validation confirms
the completed distributed integration path and the physical-device mobile workflow. The strongest
evidence supports the completed YOLO artifacts, the VLM training pipeline, and the implemented
backend and mobile architectures. The principal limitations are weak current VLM prediction
reliability, the need for broader automated test coverage, production-scale hardening, and the
requirement for agricultural expert validation before any real-world advisory deployment.
