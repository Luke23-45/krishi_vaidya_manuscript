\PrelimEntry{Abstract}

​Smallholder farmers in Nepal often lack timely access to plant disease diagnosis, as expert consultation is sparse in rural areas and unavailable at the moment symptoms first appear. This project presents Krishi Vaidya, an integrated crop-health diagnosis-support system that connects a YOLOv8 plant-part detector, a Qwen2.5-VL vision-language model for disease interpretation, an Express/Mongoose backend for orchestration and advisory generation, and a React Native/Expo mobile application for offline-aware farmer-facing delivery. 

The YOLO detector was trained on a curated dataset of 30,981 images with 147,467 annotations
across eleven plant-part classes, achieving F1 of 0.73 and mAP@50 of 0.76; its INT8-quantized
variant retains 98 percent of baseline performance at 1.87$\times$ compression, confirming
feasibility for mobile deployment. The vision-language model, fine-tuned from
Qwen2.5-VL-3B-Instruct using LoRA adapters with 4-bit quantization over three training epochs,
produces low evaluation loss but a 67.7 percent parse-error rate on the independent test set,
identifying output parseability as the principal bottleneck for structured diagnosis.

The vision-language model, fine-tuned fromQwen2.5-VL-3B-Instruct using LoRA adapters with 4-bit quantization over three training epochs,produces low evaluation loss but a 67.7 percent parse-error rate on the independent test set,identifying output parseability as the principal bottleneck for structured diagnosis. 

​ The backend validates uploaded images, orchestrates VLM inference, and assembles schema-validated bilingual advisory responses through a layered API with JWT authentication and scan-domain test coverage. The mobile application supports image capture, on-device detection using packaged TFLite models, local SQLite persistence, offline scan queuing with cached advisory fallback, crop-plot management, and bilingual result presentation in Nepali and English. End-to-end integration was verified through distributed deployment on physical Android devices. 

The main contribution is an architecture: a working prototype tying together trained models, a validated backend and an offline-aware mobile interface in one diagnosis workflow, presenting parseability with classification accuracy as a first-class evaluation metric. As the VLM does not yet provide any reliable diagnostic output and the agricultural experts advisory content has yet not evaluated, both will be a prerequisite before any field deployment apart from the current prototype.
