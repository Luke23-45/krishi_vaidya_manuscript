\chapter{SYSTEM ANALYSIS}

\ChapterSection{System Analysis}

The four subsystems introduced in Chapter 1---YOLO detector, VLM service, backend API, and
mobile application---are analyzed here as parts of a single workflow that spans model inference,
backend orchestration, local mobile storage, offline behavior, and farmer-facing advisory
presentation.

The primary users are farmers or field-level agricultural users who capture crop images and
review advisory output. The backend and model services act as system actors that validate input,
perform inference, generate structured responses, and store scan history.

\ChapterSubsection{Object-Oriented Analysis}

The dominant domain objects are User, CropPlot, Scan, Diagnosis, Advisory,
CropTask, CropNote, and local mobile repositories. The backend stores these
entities through Mongoose models and repositories, while the mobile application maintains local
representations through TypeScript types, repositories, SQLite-backed datasources, and feature
view models.
